# 処方箋入力チャレンジ PWA

## バージョン情報

- 現在のバージョン：v8.0.0
- 画面右上とフッターにバージョン情報を表示します。
- 「最新版に更新」ボタンでService Workerキャッシュを削除し、GitHub Pages上の最新ファイルを再取得します。


GitHub Pagesで公開できる、処方箋入力練習用のPWAです。
患者情報と処方内容を各項目1行ずつ入力し、正確さと入力速度でスコアを計算します。

## 主な機能

- 1枚入力、3枚入力、5枚入力、10枚入力、エンドレスモード
- 患者氏名、生年月日、保険番号の入力判定
- 内服薬：薬品名 → 用量 → 用法 → 日数
- 外用薬：薬品名 → 処方された全量 → 使用部位 → 用法
- 頓服薬：薬品名 → 1回使用量 → 服用（使用）タイミング → 回分
- 生年月日は `19490308` のように8桁入力すると `1949/03/08` 形式に自動整形
- 用量・日数・回分は数字のみで入力
- 薬品名をかな・ローマ字で3文字以上入力すると入力欄直下に候補表示
- 用法は `朝` など1文字以上入力すると、`分1 朝食後` や `分2 朝夕食後` などの候補表示
- 候補クリック、上下キー、Enter、Tabで候補確定
- 候補を使わず最後まで手入力も可能
- EnterキーまたはTabキーで次の入力欄へ移動
- GAS連携による全国ランキング
- PWA対応、Service Workerによるキャッシュ更新

## GitHub Pagesへの公開手順

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内のファイルをリポジトリ直下へアップロードします。
3. GitHubの `Settings` → `Pages` を開きます。
4. `Build and deployment` の `Source` を `Deploy from a branch` にします。
5. Branchを `main`、フォルダを `/root` にして保存します。
6. 表示されたURLを開くとゲームが起動します。

## GASランキングについて

`app.js` にランキング送信用のWebアプリURLを設定済みです。
ゲーム画面にはURLを表示しません。

GAS側を差し替える場合のみ、`app.js` の `DEFAULT_GAS_URL` を変更してください。

## GASの作成手順

1. Googleドライブで新しいスプレッドシートを作成します。
2. `拡張機能` → `Apps Script` を開きます。
3. `gas/Code.gs` の内容を貼り付けます。
4. 保存します。
5. `デプロイ` → `新しいデプロイ` を選択します。
6. 種類は `ウェブアプリ` を選択します。
7. 実行ユーザーは `自分`、アクセスできるユーザーは `全員` にします。
8. デプロイして発行されたURLを、必要に応じて `app.js` の `DEFAULT_GAS_URL` に設定します。

## 入力判定仕様

- 全角・半角の差は吸収します。
- 空白や句読点の差は吸収します。
- 完全一致は高得点になります。
- 軽微な入力差は部分点になります。
- 患者情報もスコア対象です。

## 注意

このゲームの処方箋・患者情報はすべて架空データです。
実在の患者情報や実処方は登録しないでください。
